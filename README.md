# British Compliance Guide

UK workplace compliance reference site.

## Stack
- Next.js 15 (App Router, static generation)
- MDX for content
- Tailwind CSS
- Hosted on Vercel

## Content
Pillar pages live in `src/content/pillars/*.mdx`. Edit those files on GitHub directly — Vercel auto-deploys within 60 seconds of commit.

## Local development (optional, advanced)
```
npm install
npm run dev
```

For non-coders: don't run anything locally. Edit on GitHub, let Vercel deploy.
